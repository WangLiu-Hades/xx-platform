# Vue 前端原型迁移修改说明

业务依据为《平台功能设计（原始）》PDF，工程依据为 docs/system-design，唯一接口源为指定的 api/openapi.yaml。PDF 与 OpenAPI 原文件未修改，SHA-256 已复核。

## 工程与界面

- 原静态入口迁移为 Vue 3 + TypeScript + Vite + Element Plus + Pinia + Axios + ECharts，并使用 OpenLayers 实现地图。登录和 28 个菜单由 11 类页面承载，按页面拆包。
- 原四份源码备份于相邻 prototype-v1-baseline/；活动目录移除旧 app.js、app.css。
- 完成检索、统计、真实右键菜单、表单、抽屉、地图选择与时间轴、分析任务、集合运算、库与档案、布控、模型、运维、报表和系统管理的展示与交互。
- 从 OpenAPI 生成 193 个操作、581 个 Schema；保留完整契约作审计，运行时按需加载精简校验契约。主 JS 包约 270 KB，校验包约 570 KB，图表和地图独立拆包。
- 固定依赖版本及锁文件，更新运行说明、UI/UX 设计、系统说明和 API 生成约定中的旧技术描述。

## 后端接口边界

- Mock 仅使用合成数据和本地存储；HTTP 使用本站 /api/v1、Cookie、CSRF、幂等键、If-Match、分页/游标和运行时校验，不回退为演示结果。
- 伴随、碰撞、区域分析表单使用后端目标代理 ID；区域框选提交 WGS84 多边形。编辑保留任务快照并调用修订接口。
- 人像支持分类上传策略、ACTIVE 文件检查、异步检索任务、服务端相似度、游标结果和受控图像下载。
- 人员库、设备和数据集导入读取服务端模板和上传策略；上传检查完成后提交导入任务，任务中心展示进度、逐行错误与成功结果。
- 地图接入轨迹、采集详情、热力和区域摘要；按目标分组绘线，支持 IMSI/IMEI 条件与 Context 游标复用，右侧 11 项资料读取授权档案。
- 档案接入关联目标、证据、画像和综合轨迹；模型标签结果读取模型结果接口。模型及设备表单使用后端参数定义，批量设备配置仅选择共同可写参数。
- 通知和布控读取通知模板，明确计划、接收人、能力门禁；报表、日志、导出和任务文件通过契约接口提交或下载。

## 审计修正

- 修正响应式筛选、快速切页路由、错误登录清空仓库，以及退出后残留弹窗、导入内容和选择状态。
- 修正带时空信息的伴随弹窗不能保存、综合轨迹只包含第一类数据、地图复位残留轨迹、数据集侧栏忽略当前筛选等问题。
- 分析任务按分析日期查询；详情导出只包含所选结果；分析数据集保存服务端任务结果快照，避免仅保存当前页或误扩大范围。
- 二次检索传递授权目标 ID，避免将脱敏号码作为精确条件。档案检索区分外貌、特征码、姓名，关联目标检索保留完整观测区间。
- 人员更正不预填或反写脱敏姓名、电话和证件号，只提交明确填写的更正值，并要求授权证据。编辑人员库保留原授权范围；已有用户/角色编号只读。
- 修正布控选人和数据类型继承、邮件误写短信日志、HTTP 运维界面混入模拟图表、ECharts 异步初始化和图例访问状态。
- Mock 导入先全量校验再一次提交；Excel 解压按流检查 20 MB 上限，避免解压完成后才限制；支持自身导出文件再次导入。
- 保留超级管理员最高权限，阻止重复角色名称、删除被引用角色、删除未禁用用户等无效操作。
- 会话变化后丢弃旧响应、旧下载及旧 401；取消失效页面请求和过时登录流程。

# 2026-10-25 前端侧补齐（首链联调前置）

- 修正围栏/车牌/MAC/人像检索列表"设备"列显示 UUID：检索后按本页出现的 deviceId 批量补齐设备字典（`listDevices` 的 `ids` 筛选，单次最多 100 个），字典补齐失败不阻断检索，列表退回显示原始 ID。
- 修正任务中心"状态"列显示英文枚举：统一走 `labels` 映射（`SUCCESS`→成功、`RUNNING`→运行中、`CANCELLED`→已取消）；"下载任务结果"按钮改用原始状态判断，避免映射后失效。
- 新增 401 静默续期：`client.ts` 暴露 `bindSessionRenewal`，收到 401 时先续期一次并重放原请求（幂等键复用，避免同一次重试被后端当成两次业务），续期失败才清理身份回登录页；平台侧在剩余有效期不足 5 分钟时主动续期并重新获取 CSRF。
- 新增错误分级文案 `describeError`：数据范围不足、无操作权限、版本冲突（提示刷新）、上下文过期（提示重新查询）、能力未开放、服务不可用分别提示；页面级 410 在顶部给出"重新查询"按钮。
- 任务取消改为异步体验：提交取消后继续轮询到 `CANCELLED`/终态，按钮显示"取消中…"，避免用户以为未生效。
- 契约桩补 `GET /devices`（支持 `ids` 筛选）与 `GET /_stub/expire`（把会话置为过期但允许续期恢复），自检增至 **22/22**；`npm run evidence` 增至 **14 个场景，14/14 通过**，新增"401 静默续期并重放"与"410 重新查询"两格。
- 验证：类型检查 0 错；单测 **297 项**通过（新增 2 项续期用例）；Mock/HTTP 双构建通过；28 页 Mock 冒烟 0 错误。
