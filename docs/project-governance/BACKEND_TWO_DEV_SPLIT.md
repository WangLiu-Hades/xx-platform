## 共享层与跨域边界

1. `common/`、`infra/`、`config/`由DEV-01主写；DEV-02调用公开接口，有新增需求提交评审，不复制响应壳、权限或基础设施。
2. 公共TaskStore、`async_task`状态机、租约、取消、重试、发布指针由DEV-01集成维护。DEV-02创建领域任务调用该接口；DEV-04计算与写入当前尝试结果，通过经审查的同事务发布接口提交，不能自建任务终态服务。
3. 数据库迁移由DEV-01统一合并发布；DEV-02提交领域迁移片段，DEV-04提交数据映射、索引及查询提案。禁止两人直接各自改库或跨域直接写表。
4. 设备、场所、设备枚举及八类报表的公共API归DEV-01；DEV-02只读引用实体或通过公开服务使用报表，不因此取得写权限。报表计算由DEV-04交付。
5. 通知、投递、回执、频控及送达记录公共API归DEV-01；DEV-02消费只读服务。外部动作UNKNOWN先对账，不能因重试重新发送已成功的动作。
6. DEV-02负责M04/M13的公开聚合/地图API；DEV-04提供查询和指标，DEV-03做页面/GIS交互。M06统计、M12报表等同样会消费DEV-04结果，旧分支“甲对数据侧依赖为0”不作为等待或验收依据。
