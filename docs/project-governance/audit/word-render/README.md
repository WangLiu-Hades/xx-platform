## 怎么使用

先核上一级验收记录及对应源文档哈希，再顺序打开PDF或page-N.png查看，页码按数字顺序，不按字符串顺序。需要重渲染先按上级脚本说明准备工具和匹配PDF。

## 维护与检查

修改源Word后原图不能继续当新版本验收，须重新导出、渲染并逐页核查。保留历史迭代时间，文件名final不自动代表当前版本。 返回[上级入口](<../README.md>)。
