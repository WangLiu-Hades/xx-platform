# 性能与容量设计

## 建议预算

以下为**设计建议目标**，不是源需求中的 SLA。必须在 Q-001（数据量、并发、查询窗口）确认后以目标硬件和脱敏样本压测再签认。P95 从网关接收请求到响应体完成计算，排除用户浏览器绘制与外部短信通道延迟。

| 场景 | 建议目标与限制 | 验证方式 |
| --- | --- | --- |
| 普通 CRUD | P95 ≤ 300 ms；用户/权限接口强一致 | T21 并发 API 压测 |
| 有索引的有限时间窗检索 | P95 ≤ 1.5 s，首屏 ≤ 100 条；禁止无界跨年查询 | T22 分布数据、冷/热缓存 |
| 地图 bbox 聚合 | P95 ≤ 1.5 s；单次响应 ≤ 2,000 features，超额返回聚合/瓦片 | T23 缩放/平移脚本 |
| 首页快照 | P95 ≤ 1 s；每指标展示 `asOf` 和数据延迟 | T24 聚合任务及部分失败 |
| 长任务创建 | P95 ≤ 500 ms 返回 taskId；执行时长按任务类型另测 | T25 队列积压/取消/重试 |
| 导出 | 202 + taskId；单文件行数/体积达到上限时分片或 ZIP | T26 数十万行异步导出 |
| 设备/告警刷新 | 首版 10–30 秒轮询，关键告警由服务端定时匹配 | T27 负载与延迟评估 |

## 100 万、1000 万、1 亿条情景

| 总采集量情景 | 查询与写入方案 | 升级判断 |
| --- | --- | --- |
| 100 万 | 单 PostgreSQL；上述精简索引；批量接入；统计快照 | 若目标 P95 失败，先查查询计划和数据质量 |
| 1000 万 | 时间窗口强制、深页游标、按时间分区候选、批量写入和汇总隔离 | 若写入与在线读相互影响，分离汇总时间窗/只读副本 |
| 1 亿 | 月分区和保留期清理须经验证；热点查询摘要/预聚合；数据与索引磁盘预算先核算 | 复杂多条件搜索或宽表聚合持续超预算，再分别评估 OpenSearch、ClickHouse/Doris；不能同时盲引 |

阈值是触发**测量和评审**，不是声称数据库固定可承载的容量。若日增达到 1000 万，需从峰值写入、索引维护、备份窗口、保留期和硬件资源重新估算，评估独立接入队列或分析集群。

## 关键链路设计

- GIS：按 bbox、zoom、时间范围和数据类型请求；低 zoom 返回聚合/热度，高 zoom 返回限量点和轨迹；前端图层按视窗增量更新，不一次性拉全量。轨迹按时间排序、抽稀前保留原始数据供详情追溯。
- 首页：定时/增量汇总 `metric_snapshot`，卡片标记统计时间和失效状态，不在打开首页时扫描采集主表。
- 伴随/碰撞：Worker 按时间窗和空间窗过滤候选，再计算关联；任务设资源配额、最大窗口、取消检查点，API 不同步等待。
- 导出：基于冻结的筛选参数和权限范围建立任务，流式读取、分页写文件、限大小/有效期，完成后短时受控下载。导出文件不得因用户权限变化继续可取。
- 高频接入：批量提交与去重、隔离无效记录；控制每批大小和索引数量，写入与查询分别监控；需要时把采集写入与聚合 Worker 分开扩容。

## 缓存策略

首版不部署 Redis。枚举字典可在 API 进程内缓存，键 `dictionary:{version}`，配置变更事件主动失效，最长 TTL 5 分钟；miss 回源数据库，失败时保留最后已验证版本并标记过期。权限不做跨请求长期缓存，用户禁用/角色变更必须在下一请求强制生效。首页快照在数据库中有 `as_of` 和状态，避免多实例内存缓存口径不一。设备在线状态以带时间戳的权威表/汇总查询为准。未来多个实例的共享热点测得 DB 负载超预算，再为特定键引入 Redis，定义失效事件和故障回源测试。

## DB-DESIGN-2减少负载的实现约束

首页/运维共享metric_definition/scope/snapshot，接入按批次和水位增量汇总；去重数不能跨日相加，在线率不直接平均，源采集与入库量分开。大输入以文件manifest冻结，数据集用有效区间版本，报告只冻结必要预览字段；Context不复制整批采集。上传/图片/报表内容不入库。

查询使用主目标/类型/场所/设备时间索引、次目标索引和存储geometry GiST；限定时间/bbox/zoom/limit，详情按需关联payload。PG14分区唯一键必须含分区键，不能直接把现有UUID唯一主表改成月分区；需全局身份登记和全部引用迁移。详见database/index-design.md。

隔离PG14.24/PostGIS3.6.1用2万合成记录验证了目标/类型游标和bbox索引；这是计划检查，不是生产并发、容量或最低服务器资源证明。T21～T27仍须目标环境验证。
