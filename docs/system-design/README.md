## 怎么使用

阅读顺序：00 → 11 → 01 → 对应专题。前端从仓库根`apps/web/`启动并读API联调说明；后端从仓库根`contracts/api/openapi.yaml`及数据库映射开始；数据工程师结合03、数据库查询/任务设计与治理分工；测试工程师按00、10和治理审查结果建立用例。

DB-DESIGN-2于2026-10-07采用，PostgreSQL14+需搭配兼容的PostGIS构建，PG14不能使用PostGIS3.0.x。本目录包含结构及隔离验证记录，不包含生产库迁移成果。P-012仅集合ID语法已收敛，其余规则的签认状态见[统一P清单](<../project-governance/PENDING_REGISTER.md>)。

## 维护与检查

业务变化先核原始PDF，再同步API、数据库、图示、前端生成类型及测试。图示为概览，精确字段和路径以当前契约为准；职责以治理修订版为准。设计优先级为稳定性、开发复杂度、性能、扩展性；示例预算、工期和拟议技术不能自动视为已批准约束。返回[文档总入口](<../../archive/design-project-root/docs/README.md>)。
