# 界面设计系统

## 结构与组件

PC 宽屏使用左侧 224px 导航、顶部 64px 工具栏、内容最大宽 1600px；较窄视口导航折叠，表格横向滚动但操作列保持可见。卡片与地图按 12 栅格布局；表单标签对齐、错误紧贴字段；详情抽屉推荐 480–640px。按钮分主/次/危险三类，危险操作二次确认并说明影响范围。Modal 用于短流程，复杂任务新建用完整页面；Tabs 不隐藏尚未保存的内容。Chart/GIS Panel 都显示时间窗、口径、单位与数据更新时间。

| Token | 设计值 | 用途 |
| --- | --- | --- |
| 字体 | 系统中文无衬线；正文 14px，标题 22/18/16px | 持续阅读与密集表格 |
| 间距 | 4/8/12/16/24/32px | 统一节奏 |
| 圆角 | 6px 控件、10px 卡片 | 区分容器与操作 |
| 边框 | `#D9E1EA`，1px | 表格/表单与分隔 |
| 主色 | `#1769AA` | 导航、主按钮、选中 |
| 背景 | `#F5F7FA` / 白色卡片 | 工作台层次 |
| 正常 | `#147D52` +“正常”文字 | 设备/任务成功 |
| 警告 | `#B46B08` +“待处理”文字 | 延迟、部分失败 |
| 错误 | `#B42332` +“失败”文字 | 故障/危险确认 |
| 禁用 | `#9AA6B2`，同时不可聚焦或提示原因 | 无权/不可操作 |

Hover 只增强边框/底色，Selected 同时使用色块与勾选/文字，不能仅靠颜色。表格最小行高 44px，状态标签带文本，空/加载/失败占位保持布局稳定。地图点、热区和轨迹的色彩同时配图例和数值，热度不等于风险。原型中的具体数值是 Mock，不表示生产指标。
