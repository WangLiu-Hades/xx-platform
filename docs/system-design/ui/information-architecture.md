# 页面树与入口关系

```text
登录
└─ 应用壳（统一菜单 / 用户 / 消息 / 任务中心）
   ├─ 系统首页（12 类卡片、地图、应用入口）
   ├─ 数据检索
   │  ├─ 围栏检索 ├─ 车牌检索 ├─ MAC 检索 ├─ 人像检索/同人搜图
   │  └─ 人员库（M11 业务、DEV-02 页面）
   ├─ 综合分析 └─ 地图研判（轨迹/位置追踪/设备点/热力）
   ├─ 数据研判
   │  ├─ 伴随任务 ├─ 碰撞任务 ├─ 区域统计任务 └─ 数据运算/数据集
   ├─ 布控预警 ├─ 综合布控 └─ 告警结果
   ├─ 数据模型 ├─ 图码档案 ├─ 车码档案 └─ 数据态势/常驻模型
   ├─ 运维服务
   │  ├─ 运维首页 ├─ 场所管理 ├─ 设备管理/分组
   │  ├─ 设备分布 ├─ 参数配置 ├─ 运维报表 └─ 运维通知
   └─ 系统设置 ├─ 角色管理 ├─ 用户管理 ├─ 操作日志 └─ 短信日志
```

任务中心是共享入口，不另设一级业务菜单。检索/研判/布控/数据集页面互跳只传 contextId；返回保留筛选与选中状态。S1 的“数据应用”统一映射至“综合分析 → 地图研判”，S1 的“设备发布”暂映射至“设备分布”，均待 ISSUE-003/产品签认。
