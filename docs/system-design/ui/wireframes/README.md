# 核心页面线框

本目录供产品、设计、前端和测试人员确认页面结构与操作入口，内容为Markdown文本示意，无需运行服务。

## 文件与目录

| 文件 | 功能 |
| --- | --- |
| [核心页面线框.md](<核心页面线框.md>) | 登录、首页、检索、人像、地图、任务、集合、布控、档案及运维等关键页面的低保真布局；`[ ]`表示输入/操作，`{ }`表示状态/数据 |

## 怎么使用

先按[页面树](<../information-architecture.md>)定位页面，再核对线框中的筛选、表格、地图、详情和二次动作；结合[UI专题](<../../05_UIUX与交互设计.md>)检查Loading、Empty、Error、无权及部分失败等状态。交互实物从[当前原型](<../../../../apps/web/README.md>)查看。

## 维护与检查

线框不规定像素尺寸、算法或接口实现。变更后核对原始PDF、页面树、设计系统和运行组件，避免把未定阈值写成已确认条件。返回[界面入口](<../README.md>)。
