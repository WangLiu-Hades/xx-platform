# 核心页面低保真线框

线框依据 S1 的页面类型和动作。`[ ]` 为输入或操作区，`{ }` 为状态/数据；屏幕尺寸与配色不是验收标准。所有页面均叠加 Loading、Empty、No Result、Error、Timeout、No Permission、Partial Failure、Offline 状态（见 05）。

## 01 登录

```text
┌──────────────── 平台名称 ────────────────┐
│ [登录账号                         ]       │
│ [密码                             ]       │
│ [登录]  {错误提示/traceId}                 │
└─────────────────────────────────────────┘
```

## 03 围栏/车牌/MAC 通用检索

```text
导航 | [类型] [场所] [时间范围] [IMSI/IMEI 或 车牌/MAC] [查询][重置]
     | [导出] [加入数据集] {范围/数量提示}
     | □ | 时间 | 类型 | 脱敏标识 | 场所 | 设备 | 操作
     | □ | ...  | ...  | ...      | ...  | ...  | [详情]
     | [上一页/下一页]   右侧[详情/统计/轨迹/伴随/布控]
```
