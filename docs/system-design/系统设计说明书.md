# 多维数据分析平台系统设计说明书

本说明书是 `docs/system-design/` 的评审入口，面向 DEV-01～DEV-04、项目负责人、产品与安全负责人。它将 `分工` 目录中的原始功能、M01–M15 分工、人员要求、图表和预算草案转换为可开发的技术基线；源提示词与源资料均保持原样。结论是首版采用**模块化单体 API 加独立数据分析 Worker**，统一 PostgreSQL/PostGIS、服务端跨页上下文和异步任务；对无数据证明的中间件与微服务保持延后引入。

## 一页决策摘要

| 主题 | 当前主方案 | 原因与条件 |
| --- | --- | --- |
| 架构 | 模块化单体 Spring Boot API + Python Worker | 四类角色、强共享契约；重分析进程隔离 |
| 前端 | Vue 3、TypeScript、Vite、Element Plus、Pinia、Axios、ECharts | 页面/表单/图表为主；UI 组件统一 |
| GIS | OpenLayers、GeoJSON WGS84 | 以 2D 框选、轨迹、热力、设备分布为主；底图许可待确认 |
| 主库/空间/首版搜索与分析 | PostgreSQL + PostGIS | 一套数据库支持事务、时空与中等规模检索；容量待压测 |
| 缓存 | 首版无 Redis，有限进程内字典缓存和指标快照 | 当前无共享缓存收益证据 |
| 消息与任务 | PostgreSQL 任务表 + Worker 租约 | 原子提交、可追踪、组件少；积压超标再评估 MQ |
| 搜索/分析专库 | 首版无 OpenSearch、ClickHouse/Doris | 真实数据量/查询计划未给；按压测触发 |
| API | REST `/api/v1` + OpenAPI 3.0.3 | 固定资源、权限与任务状态易契约化 |
| 认证 | 服务端会话 + HttpOnly Secure Cookie | 禁用/权限变更立即生效；期限待签认 |
| 部署 | Docker Compose 四套隔离环境 | 少量固定主机与小团队适配；HA/多机要求待确认 |

## 设计范围与不确定性

八个业务一级菜单、M01–M15 模块、跨页检索→地图→研判→布控→通知链路均已追踪到模块、API、数据实体、UI 与测试。ER 图、DDL、OpenAPI、10 张架构/时序图、14 类线框、旧版 Mock HTML 基线和可运行的 Vue 3 + TypeScript 原型已作为源文件保存。核心表和接口是设计基线，不意味着已实现或性能已达标。

资料没有给出日增/历史量、并发、保留期、主机与高可用、设备协议、地图许可、人像算法和敏感数据审批规则。`00_需求追踪与设计说明.md` 给出 A-001～A-007 假设，`07_性能与容量设计.md` 给出建议预算及 100 万/1000 万/1 亿条情景；`11_架构风险与待确认事项.md` 列出 ISSUE-001～016 和 Q-001～008，分别说明证据、影响、建议与是否阻塞。
