# UI UX 与交互设计

以 S1 的八个一级入口为导航，保留源需求语义。完整页面树见 `ui/information-architecture.md`；低保真图见 `ui/wireframes/核心页面线框.md`，可运行的 Vue Mock 原型见 仓库根的`apps/web/`（通过 Vite 启动）。PC Web 是首版设计范围；移动端、大屏在 S4 出现但无详细需求，列为 ISSUE-010。

## 页面模板与交互

- SearchListPage：标题/面包屑→条件（时间、场所、类型与专属字段）→查询/重置→操作栏→表格/图片列表→分页/游标→详情侧栏→右键动作。选中 0、1、多条时动作启用表明确；区域统计/添加数据集作用于**当前查询快照**而非误用右键所在行，先展示范围与估计数量。
- TaskPage：任务筛选→新建→状态/进度→详情、结果、参数快照、取消/重试/导出。编辑运行中任务生成新版本或先停止再建，不能静默改已产出结果。
- GISPage：搜索/时间范围→地图/图层→点位列表→详情→轨迹时间轴。框选设备、框选采集事件分别标明；选择保持跨页 contextId，地图 Reset 清除临时选择并恢复查询初态。
- DashboardPage：指标卡→趋势/排行/地图→钻取和导出。各卡片带单位、口径提示、asOf；一处失败不使整页白屏。
- GalleryPage：人像图片/质量/相似度筛选、上传与下载；相似度默认值与算法待 ISSUE-007 裁定，原型只作交互占位。

## GIS 专项

地图默认 2D。bbox+zoom 请求聚合；大缩放显示聚合数量，放大后再请求限量点位。轨迹是按时间排序的目标点序列，播放/时间轴与列表同步；热力图表征设备采集量时标注时间窗口和聚合单位，不能用颜色暗示未经定义的“风险”。Tooltip 提供精简脱敏信息，Popover/Detail Panel 经权限获取详情。框选、多选、单选、图层开关、场所/设备点、选中状态、Reset 都有键盘可用替代操作。GeoJSON WGS84、错误坐标隔离和地图无底图时的列表后备在 GIS Contract 中固定。

## 完整页面状态

| 状态 | 统一行为 | 特殊场景 |
| --- | --- | --- |
| Loading | 骨架/局部进度，不阻断别的卡片 | 长任务显示 taskId/进度 |
| Empty | 明确尚无记录，保留查询条件/新建入口 | 仪表板区分 0 与尚未计算 |
| No Result | 显示条件摘要与重置 | 人像相似结果提示阈值 |
| Error/Timeout | 错误码、traceId、局部重试 | 导出失败保留参数快照 |
| No Permission | 不泄露受限对象是否存在 | 按钮隐藏仍由后端拒绝 |
| Partial Failure | 成功部分保留，失败卡片标识 | 首页/运维图表各自独立 |
| Offline | 明确网络/设备离线来源与上次更新时间 | 设备离线不误标为无采集 |

所有页面提供键盘焦点、表单标签、状态文字而非只靠颜色；表格大数据量用后端分页/虚拟列表。Design System 见 `ui/design-system.md`。仓库根的`apps/web/` 已迁移为 Vue 3 + TypeScript + Vite 的可运行前端原型，默认以合成 Mock 数据展示完整页面；HTTP 模式只按 仓库根的`contracts/api/openapi.yaml` 调用接口，待确认的算法、设备、地图授权及通知能力仍受 仓库根的`contracts/api/OPENAPI_PENDING.md` 约束。原型的 Mock 数字与结果不作为生产统计或算法承诺。
