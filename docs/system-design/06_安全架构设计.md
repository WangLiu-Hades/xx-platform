# 安全架构设计

## 身份与会话

首版采用服务端会话、随机高熵 SID、数据库只存 SID 哈希，浏览器使用同源 `HttpOnly; Secure; SameSite=Lax` Cookie；状态改变请求再校验 CSRF 令牌与 Origin。登录设置速率限制、失败审计、统一失败文案；退出或禁用用户立即撤销会话。会话采用空闲超时和绝对过期，时长、并发登录数与异地登录策略待 Q-006 签认。生产 HTTPS/TLS 是必要条件；代理到 API 和数据库的网络边界由部署方确认。选择与替代方案见 ADR-007。

## 授权矩阵与强制点

RBAC 管菜单、按钮、API 操作；Data Scope 对场所、目标类型、任务/文件所有权和档案引用再次限制。后端在列表 SQL、详情、地图 bbox、导出、结果下载、分析上下文恢复、设备命令与通知发送的每条链路强制校验。前端仅用于展示。用户被禁用或角色/场所权限变更，下一请求即生效，旧 contextId 不能越权。跨模块任务执行使用提交时经校验的范围快照，但发布结果和下载时复核当前权限；权限缩小可拒绝旧结果访问。

| 操作 | 独立权限点 | 审计与控制 |
| --- | --- | --- |
| 解密/查看完整标识 | `capture:decrypt` | 用途/对象/次数/结果、最小展示时长；审批规则待 ISSUE-014 |
| 导出/图片下载 | `capture:export`, `face:download` | 行数/范围/文件引用、重新校验权限 |
| 删除/撤销布控 | `watch:delete`, `watch:revoke` | 版本、生效时间、已通知事实保留 |
| 通知发送 | `notification:send` | 收件人哈希、模板、通道回执 |
| 参数下发/设备复位 | `device:command`, `device:reset` | 二次确认、每设备幂等、执行回执 |
| 用户禁用/权限变更 | `user:disable`, `role:grant` | 变更前后摘要、会话撤销 |
| 审计/短信日志导出 | `audit:export`, `delivery:export` | 导出者、范围、结果文件、有效期 |

## 数据分类与保护

| 等级 | 示例 | 最低保护 |
| --- | --- | --- |
| L1 公共 | 产品帮助、非业务字典 | 完整性校验 |
| L2 内部 | 设备型号、非敏感运维指标 | 鉴权、传输加密、日志最小化 |
| L3 敏感 | 账号、手机号、车牌、MAC、IMSI/IMEI、设备位置 | 角色+场所范围、默认脱敏、加密存储/受控访问、导出审计 |
| L4 高敏 | 人像/特征、个人轨迹、跨源档案关联、解密结果、布控对象 | 独立权限、用途/审批策略、短时访问、访问审计、存储密钥隔离 |

数据库盘/备份加密与 TLS 保护整体；可精确检索的敏感标识保存**密文 + HMAC 指纹**，HMAC 密钥与加密密钥分离并支持轮换。哈希只用于精确匹配，不把无盐普通哈希当作脱敏。人像文件、报表和原始接入文件在受控文件卷，数据库仅保留引用与校验值。服务端输出按字段与用户权限脱敏；日志、URL、前端 localStorage 和错误信息不得存明文标识。不是所有数据库列都应用层加密；非敏感维度保持索引能力。

## 审计与保留

应用日志、操作日志、安全审计分开。`audit.audit_event` 追加存储 who/when/what/target/before-after 摘要/result/traceId，数据库权限禁止应用账号 UPDATE/DELETE；高风险操作失败也记录。审计导出单独授权，下载再次校验。具体法定/机构保留期与脱敏规则没有来源，须 Q-006 确认；此设计不擅自给出法定期限。

**未解决的安全阻塞**：原文的“非涉密用户发送加密数据给涉密用户”缺少审批、密钥与明文暴露规则（ISSUE-014）；人像相似检索与跨源身份关联的准确性/复核流程未定（ISSUE-007/015）。相应功能在规则签认前只保留契约与 Mock，不上线真实敏感操作。

## 物理存储与权限复核（DB-DESIGN-2）

auth.user_session使用sid_hash、idle_expires_at、absolute_expires_at和revoked_at；auth.csrf_session保存绑定hash。用户user_scope、角色role_site/role_data_type与人员库范围分别存储，P-002未签认前不猜测合并/扩大有效权限。target_lookup和profile_identifier_index使用独立HMAC/规范化版本；解密申请与明文结果授权采用operation.decryption_request/decryption_result_grant，P-008确认前关闭能力。

审计表禁止UPDATE/DELETE，应用账号同时不能TRUNCATE或拥有迁移owner权限；仅PUBLIC撤权不能约束被单独授予权限的角色。命令和解密确认记录为不可变安全事实。文件、旧Context、数据集成员、任务结果和报告下载均重新校验当前范围；共享不放宽源数据权限。密码/用户生命周期与保留期P-021未定，不由表默认值决定。
