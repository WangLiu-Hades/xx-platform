# 可靠性与可观测性设计

## 任务与副作用

`async_task` 包含 taskId、owner、类型、优先级、状态、progress、创建/开始/结束时间、参数快照、结果引用、错误码/消息、retryCount、租约持有者/到期、幂等键和 traceId。领取使用 `FOR UPDATE SKIP LOCKED` 和短租约；Worker 心跳续租；租约过期后由扫描器重排，但执行函数必须按业务幂等键去重。重复点击创建布控/数据集运算返回既有任务 ID 或明确冲突，不产生双份结果。

| 场景 | 超时/重试/补偿 | 不可机械套用的点 |
| --- | --- | --- |
| 检索/API | 请求超时、时间窗/行数限制；只读查询可由用户重试 | 不对慢查询无限自动重试 |
| Excel/报告 | Worker 断点/重新生成临时文件，成功后原子发布 `file_asset` | 中途文件不暴露；过期清理 |
| 分析/集合运算 | 固定参数/算法版本，结果写临时版本，成功后切换可见引用 | 取消/失败不得留半成品 |
| 短信/邮件 | 通道超时、有限指数退避、供应商回执对账、死信待人工 | 外部是否送达不明时先查回执，避免盲重发 |
| 设备参数/复位 | 每台设备独立命令 ID、TTL、确认回执；仅失败项重试 | 成功项绝不重复下发；高风险命令需确认/审计 |
| 布控规则 | 规则版本和生效区间；命中事件唯一键/频控窗口 | 撤销不抹除已发送告警 |

跨数据库事务仅限本库；外部设备/通知采用任务记录、回执和补偿状态。首版没有多服务远程调用，不引入通用熔断器；对确有外部通道的适配器设置超时与隔离线程池。限流施于登录、搜图、导出和大查询；首页各卡片独立降级。

## 日志、指标、追踪

所有请求/任务携带 `traceId`，贯穿 API、Worker、审计、通知和设备回执。应用日志记录结构化事件、耗时、错误码，不记录明文 IMSI/身份证/图像或完整查询；操作日志记录业务动作；安全审计是追加、权限隔离、定期校验的独立表与备份。审计至少记录 who、when、what、target、before/after 的受控摘要、result、traceId；敏感字段变更前后不存明文。

最低指标与告警：API QPS/P95/错误率，数据库连接/慢 SQL/锁等待，任务队列长度/最长等待/失败率/租约过期，接入速率/拒绝率/重复率，设备在线率，告警处理延迟，通知成功率，文件卷容量与备份成功率。阈值由 Q-001/Q-002/Q-005 签认；初期以连续异常趋势、队列持续增长、备份失败为告警条件，避免捏造正式 SLA。

日志/指标/链路分别存储并以 traceId 关联；首版可使用 API/Worker 日志、OpenTelemetry 接口和 Prometheus/Grafana 等价采集，不要求独立链路数据库才能开始，但必须可从错误任务定位到输入批次、算法版本和失败点。

## 演练与恢复

DEV-04 在 TEST/UAT 演练：API 重启不丢任务、Worker 崩溃租约回收、数据库短断、磁盘满、批次回放、设备离线、短信超时/回执不明、错误版本迁移回滚、备份恢复。每次记录版本、数据范围、traceId、预期/实际结果。RPO/RTO、备份频率和保留期未给出，生产前必须签认；数据库与文件资产需可在同一时间点恢复。

## 持久化执行协议（DB-DESIGN-2）

async_task、task_attempt、task_event分别存执行当前状态、尝试历史、状态事件。PENDING先准备输入并转QUEUED；领取只执行QUEUED任务。每次claim提高lease_generation，续租和发布校验worker、generation、RUNNING、未过期租约；旧Worker写入返回0则退出。领域结果先写当前attempt，完成事务校验租约并切换published_attempt_no；失败/取消不会公开半成品。query-examples.sql列出领取/完成模板。

业务幂等账本的(user_id,operation_id,key)和request_digest区分同请求重放与同键不同内容409；outbox与consumer_inbox保证本库意图可恢复，外部副作用仍依赖回执/幂等能力。数据回放不覆盖稳定source_event身份；daily通知(plan_id,occurrence_key)唯一且键由服务规范生成；命令逐台attempt，成功不重发、UNKNOWN先核对。

清理需按FK、保留期和文件引用执行；旧尝试、固定数据集版本、历史证据和报告预览不得在活跃任务仍引用时删除。schema.sql不是旧库升级脚本，迁移及恢复见database/migration-plan.md。
