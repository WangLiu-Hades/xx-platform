# 现有原型迁移至 Vue 3 技术基线的全面评估

评估日期：2026-10-08，Asia/Shanghai。对象：`apps/web`。

## 1. 结论与估算边界

现有界面可以迁移，视觉布局、业务入口和已验证的交互应保留。需要重构的是页面渲染、状态、事件和数据访问结构，属于中等偏大规模的前端迁移。本次只评估并检查，不实施迁移，也不修改现有原型。

**在保留虚构 Mock 后端和示意地图、功能与当前原型等价的前提下，基础工作量为 46–73 人日；加 20% 不确定性预留后，规划预算为 56–88 人日。** 1 人日按 8 小时工程投入计算，含该工作包内的检查。熟悉 Vue 3/TypeScript 的 1 名工程师全时投入约 12–18 个工作周；2 名工程师约 8–12 个工作周。这里的周数考虑公共基础的前置依赖、集成与复核，不能简单按人数相除。未确认实际人员及熟练度，未实施迁移试点，工期不是承诺。

这一预算包括 Vue 3、TypeScript、Vite、Element Plus、Pinia、Axios、ECharts 的实际使用，现有 28 个导航页和登录，214 项文字需求映射，69 组既有浏览器用例的适配与复跑，以及本次发现的输入、权限失效和持久化问题的修正。库仅安装而不参与业务流程，不算迁移完成。

| 场景 | 基础工作量 | 含 20% 预留的预算 | 范围 |
|---|---:|---:|---|
| A：保留 Mock 的七项技术栈完整迁移 | 46–73 人日 | 56–88 人日 | 当前功能等价；强类型 Mock、Axios 访问适配、ECharts 图表、Element Plus 控件；保留示意地图 |

## 5. 七项技术各自需要落实的工作

| 技术 | 实际改造 | 验收点 |
|---|---|---|
| Vue 3 | SFC/Composition API；共享组件、组合式函数；视图改为 Vue 模板和事件 | 不依靠 `v-html` 执行旧整页字符串；弹窗、右键和跨页行为与基线对应 |
| TypeScript | `strict`；实体/展示模型/事件/状态的明确类型；运行时校验外部数据；生成 DTO 与人工映射分离 | `vue-tsc` 成功；关键边界没有靠 `any`、`@ts-nocheck` 或不校验断言绕过错误 |
| Vite | 入口 `main.ts`、开发代理、资源/子路径、构建分包、依赖锁及启动脚本 | 干净环境 `npm ci`、类型检查、构建、静态预览均成功；离线部署资产齐全 |
| Element Plus | 逐步替换按钮/输入/选择/表单/表格/分页/Tabs/Dialog/Drawer/反馈；自定义右键菜单保留 | 不改变规定入口与位置；选择、键盘、焦点、禁用、表单错误及弹层堆叠正确 |
| Pinia | 身份/权限、跨页 Context、数据集、任务等共享状态；短期 UI 状态留组件/composable | 返回保留已约定条件/选择；身份切换、范围收缩、登出清理正确；失效持久化可恢复 |
| Axios | 统一 HTTP/Mock 传输适配、超时/错误/取消、文件下载与上传；同页快速查询竞态处理 | 页面不直接改“数据库数组”；模拟成功/失败/超时走统一服务边界，后续可切换真实传输 |
| ECharts | 首页/运维/设备历史/报表/在线率图的数据与 option 构建；主题、图例、单位/时间及导出联动 | 容器可见后初始化，尺寸变化 resize，卸载 dispose；导出数据与图表源一致 |

Vite 的 TS 转译不执行类型检查，必须单独运行 `vue-tsc`；参考 [Vue 官方 TypeScript 文档](https://vuejs.org/guide/typescript/overview.html)。Element Plus 表格提供行右键事件，保留选择需要稳定 `row-key`；但“全选当前授权查询”与分页/游标的数据范围仍需应用实现，不能将组件的页内勾选当成全量选择。[Element Plus 表格文档](https://element-plus.org/en-US/component/table.html)

Pinia 中拆分明确职责，读取响应式 state 时注意 `storeToRefs`，不把每一个临时弹窗状态都持久化。[Pinia 文档](https://pinia.vuejs.org/core-concepts/) Axios 请求可用 `AbortController`；还须比较请求版本，避免较旧响应覆盖较新条件。[Axios 取消文档](https://axios-http.com/docs/cancellation) ECharts 的 resize/dispose 属于必须处理的生命周期成本。[ECharts 容器文档](https://echarts.apache.org/handbook/en/concepts/chart-size/)

建议结构为 `src/{router,layouts,views,components,composables,stores,types,services,api/generated,mock,utils,styles}`。Mock seed 与页面完全分离，明确持久化 schemaVersion；服务 DTO 和页面 ViewModel 通过映射转换。JSON/XLSX 输入先校验，再进行完整事务式应用。生成 API 代码可替换，禁止手改生成文件解决契约错误。

## 6. 接口适配容易被低估的差异

当前 `api/openapi.yaml` 与 `api/api-conventions.md` 已比原型 Mock 模型严格。场景 A 提供服务边界及类型准备，**没有宣称下列正式语义已全部落地**；场景 B 才包含已确定语义的完整契约 Mock 改造。

| 当前原型 | 正式契约 | 需要的适配 |
|---|---|---|
| 目标明文字符串、短 Mock ID、场所名关联 | UUID、`targetType+targetId`、独立 site/device/person/member/profile ID | 合成稳定 UUID/关联映射；脱敏文字仅显示，不从显示文字推导真实身份 |
| 全部数组已在客户端，统一页码分页 | 管理页码；采集/轨迹/日志/结果 cursor | 类型化分页适配、cursor 历史、条件变更重置、稳定选中和完整范围 Context |
| 页面参数直接携带目标/时空数组 | 服务端 Context，`contextId/expiresAt`、预览截断与全范围 | 过期/权限变化反馈；URL 仅放安全引用，不放敏感标识与原始查询 |
| 创建后即时成功、中文状态 | 202 执行引用与分型资源；排队/运行/终态/取消/重试 | 状态映射、轮询、进度、取消确认、结果未就绪/已过期，不丢领域 ID |
| 设备参数直接写本地、全部修改成功 | 幂等、If-Match/ETag、逐设备命令回执与部分失败 | 防重复提交、版本冲突、逐项失败展示；写请求不盲目重试 |
| XLSX/ZIP 由本机直接生成 | 文件上传处理/隔离/ACTIVE；异步导入/导出及受权文件下载 | 文件资产 ID、错误行、上传不等于导入成功、过期/JSON 文件错误处理 |
| 表单可回填原始电话、模拟定时发送 | 脱敏接收人/RETAINED、服务端通知执行/回执 | 原值保留语义；客户端不重复创建定时发送事实 |
| 客户端用户/密码、演示身份、默认角色 | 拟议 Cookie Session/CSRF、服务端权限与范围 | /me、401/403、登出/禁用/权限变化；安全方案待签认，不能按 Mock 上线 |

现有契约、生成参数和已确认规则可以复用。193 个接口定义既不是 193 个必需的页面调用，也不是 193 个可立即上线的能力。`OPENAPI_PENDING.md` 仍列认证、权限、指标、算法、人像、解密、地图许可、设备及通知等待签认项，其中 P-012 集合语法已收敛。未决能力在正式环境以服务端能力目录关闭；独立演示环境可以继续显示明确标识的虚构流程。

## 7. 本次实际重现的风险

以下属于已确认观察，必须纳入迁移修正与回归。不是对当前服务器的远程攻击证明；原型没有真实业务服务器。本次没有为使评估好看而隐藏现有问题，也没有改动原型实现。

| ID | 观察与来源 | 验证方式 | 迁移处理及通过标准 |
|---|---|---|---|
| R-XSS | `app.js:85` 的人员性别 `p.sex` 未转义进入表格；`app.js:149` 从导入文件接受 sex | 隔离浏览器导入虚构 JSON，良性 HTML 错误事件成功设置内存标记 | 模板文本渲染＋字段枚举/结构校验；HTML 样本被拒绝或以文本展示，标记不可执行；同时审查其它动态插值/URL |
| R-AUTH | `app.js:23` 中角色找不到回退到首个角色，其菜单/场所范围为管理员范围 | 删除隔离 Mock 数据的分析员角色，原账号仍能显示 28 个菜单 | 不存在/过期身份与角色必须拒绝访问；正式数据由服务端逐请求校验。前端隐藏不代表授权安全 |
| R-STORAGE | `app.js:19` 仅捕获 JSON 解析错误，无结构/版本校验；登录直接 `db.users.find` | 隔离 localStorage 写入合法 JSON `{}`，登录出现页面异常 | schemaVersion、运行时结构校验、版本迁移或明确恢复；初始化/存储失败不白屏；正式敏感数据不进入本地存储 |

证据：`apps/web-migration-assessment/baseline-verification.json`。样本仅在新建的独立无界面浏览器环境运行，无真实用户数据、无外发信息，不影响用户当前浏览器。

## 8. 其它必须防止的迁移回归

| 风险 | 当前依据/为何会发生 | 控制与检查 |
|---|---|---|
| 右键变成普通按钮或漏动作 | 集中 contextmenu，九项顺序及 0/1/多选约束 | `row-contextmenu`/图片/设备点原生右键；菜单跟随鼠标、边界/滚动/Escape/外部点击关闭 |
| Element Plus 样式破坏布局 | 旧 CSS 有全局 input/select/button/table/h 等规则及固定面板布局 | 分离设计 Token/业务布局和控件样式；按原尺寸与 1100px 视口核对，不用默认控件尺寸重排需求区域 |
| 弹层、焦点、上传和拖拽回归 | Dialog/Drawer/Popper Teleport 改变 DOM/层级；旧选择器依赖 `#view` | 明确菜单与弹层 z-index、挂载目标、focus return、键盘循环；上传/拖拽/框选实测 |
| 当前页被误当全结果 | 旧表格全选查到的是完整本地 rows | 选择范围区分当前页/显式 ID/全查询 Context；导出、统计、集合与批量权限一致 |
| 旧查询或身份的响应覆盖新状态 | 原型仅短 setTimeout，没有真实并发 HTTP | AbortController＋请求代次；身份/条件变化取消；不同页面和账号不可复用旧敏感缓存 |
| 定时器/监听/图表泄漏 | 原全局事件只注册一次；改成页组件后会反复挂载 | 生命周期清理、图表 dispose、轮询单实例；定时通知只在演示适配器模拟，真实发送归后端 |
| Pinia 直接改库、重绘导致状态丢失 | 多集合与页面状态杂糅、跨页 scope 和 history | 领域 action/service，独立查询状态；返回恢复与详情过期/删除后处理；相关引用完整性检查 |
| 日期/时区或结束边界变化 | Mock 本地格式和闭区间；契约 UTC、Asia/Shanghai、半开区间 | 显式格式转换；等于边界、跨日/月/年、报告自然周期测试，不让控件默认转换决定业务 |
| 导入/导出兼容及资源耗尽 | 客户端 ZIP/XML/CSV/JSON 解析，缺少正式文件限制 | 类型/枚举/未知列/行数/大小/解压边界；失败原子性；文件名/Blob 错误/Excel 读取验证；不宣称 ZIP/XLSX 能覆盖所有复杂工作簿 |
| 地图坐标被当真实位置 | 当前 x/y 是百分比 CSS 坐标 | Mock 图与合成 WGS84 明确分开；真实坐标转换需可信来源，不把百分比直接当经纬度 |
| 图表及测试误判 | SVG polyline 可能变 canvas；DOM、原生 select、localStorage 断言依赖实现 | 测试关注图例/数据/行为；图表适配器保留可访问摘要；测试选择器更新但保留行为断言 |
| 生产刷新/子路径/离线失败 | Vite 产物与原直接打开 HTML 的运行方式不同 | 静态服务 dist；部署 base 路径、Router fallback 或 hash 模式明确；资源/字体本地化 |
| 仅有编译类型，外部数据未校验 | TypeScript 类型在运行时不能验证 JSON/文件/服务响应 | 边界解析器/schema，分型错误反馈；避免类型断言替代校验 |

Vue 文本插值的转义可以减少字符串渲染风险，但不替代输入校验、URL 处理和后端授权。[Vue 安全文档](https://vuejs.org/guide/best-practices/security.html) Vite 的客户端环境变量不能存密钥。[Vite 环境变量文档](https://vite.dev/guide/env-and-mode.html) History 路由需要部署回退配置，静态托管条件不明时要明确模式及刷新行为。[Vue Router 文档](https://router.vuejs.org/guide/essentials/history-mode.html)

## 9. 建议实施顺序与关键路径

1. **冻结当前验收基线与开展代表性试点。** 保存来源哈希、映射和测试；先做登录/壳、围栏检索的右键/统计/轨迹/返回闭环，再加一个图表与一次文件流程。计划 3–5 人日，计入上述工作包，不额外叠加。用实际试点结果重新校准每组人日、依赖和兼容性。
2. **完成公共基础。** 类型/Mock 服务/Pinia/Router、Element Plus 表格和弹层、ECharts 包装、输入校验和测试工具。确认选择与权限策略后，各页依赖同一实现。
3. **按业务链路迁移。** 检索→统计/地图→分析/布控/数据集；再迁移档案/模型、管理/配置/报表/通知与日志。首页最后汇总集成可减少口径和接口重复改造。两人时按页面组分工，公共状态/服务指定一致的接口负责人。
4. **完成横向修正与回归。** 逐模块自测后，执行 W07 的全量用例、映射、视觉、输入/权限/存储/并发/生命周期检查。发现偏差先修，再复跑受影响链路。
5. **替换运行入口并交付。** 原型目录内最终使用 Vue/Vite 源码；旧版本留在独立基线位置，恢复方式记录。用实际构建产物而非开发服务器完成交付验收。

公共表格/选择策略、上下文与数据服务是关键路径。设备/用户普通 CRUD 不能代表地图、数据集或跨页研判的迁移难度。AI 辅助可减少重复模板编写，但没有试点数据，不据此宣称固定加速比例或几天内全部完成。
